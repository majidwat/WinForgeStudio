# Claude Code instructions

Before doing any work in this repository, read the root [AGENTS.md](AGENTS.md) and follow it as the canonical instruction set.

Then read [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) and [docs/ROADMAP.md](docs/ROADMAP.md) when relevant.

Do not make destructive Windows changes, disable security controls, add background services, change the technology stack, or perform broad refactors without explicit owner approval. Always inspect first, keep scans read-only, and report exactly what was built and tested.
