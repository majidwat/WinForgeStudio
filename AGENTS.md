# WinForge Studio AI Agent Guide
The project is migrating to Rust + Slint; WPF is legacy. Keep dependencies lean and prioritize responsive, modern UI. Read-only inspection only by default. Never disable Defender, firewall, updates, or protected services. Never run hidden/downloaded scripts. Any system mutation requires explicit approval, exact before/after values, risk explanation, journal, validation, and recovery. Do not elevate automatically. UI lives in `ui/`; system logic in Rust modules. UI callbacks must remain thin. Long operations must be async/cancellable and report progress/errors. Keep GitHub as source of truth. Work on migration branch until Windows build/smoke tests pass. Never claim tests passed without running them. Clearly label placeholders.
